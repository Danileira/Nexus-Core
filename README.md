Nexus-Core — Sistema de Gestão Logística Enterprise
English version below

🇧🇷 Sobre o Projeto
O Nexus-Core é uma solução SaaS corporativa de alta performance desenvolvida para a gestão completa de operações logísticas, controle de frotas, alocação de motoristas e despacho de viagens em tempo real.

O sistema integra uma arquitetura robusta com backend em Python (Flask) e um front-end moderno em React (Vite) com interface dark-mode imersiva (glassmorphism), suporte a internacionalização nativa (PT/EN), busca global, central de notificações e relatórios operacionais exportáveis em CSV.

🧠 Arquitetura e Inteligência Artificial (IA) Integrada
O projeto foi estruturado para suportar fluxos avançados de processamento de dados e tomada de decisão preditiva baseada em IA:

Orquestração de Dados em Tempo Real: Comunicação assíncrona otimizada entre o banco de dados relacional (SQLite/SQLAlchemy) e os endpoints REST do Flask.

Mecanismos de Análise Preditiva e Logística: Preparado para receber modelos de Machine Learning focados em otimização de rotas geográficas, previsão de manutenção de frotas e alocação inteligente de motoristas com base em histórico de desempenho.

Internacionalização Dinâmica (i18n): Estrutura modular escalável para tradução automática de interfaces e relatórios voltados para o mercado global.

🛠️ Tecnologias Utilizadas
Backend: Python, Flask, Flask-SQLAlchemy, SQLite, RESTful API.

Frontend: React, Vite, JavaScript (ES6+), CSS3 Personalizado, Lucide Icons.

Recursos Avançados: Filtros dinâmicos em tempo real, gráficos de ocupação da frota, exportação de relatórios em CSV e suporte multilíngue (PT/EN).

🇺🇸 About the Project
Nexus-Core is a high-performance enterprise SaaS solution designed for comprehensive management of logistics operations, fleet control, driver allocation, and real-time trip dispatch.

The system integrates a robust architecture featuring a Python (Flask) backend and a modern React (Vite) frontend with an immersive dark-mode UI (glassmorphism), native internationalization support (PT/EN), global search, notification center, and exportable operational CSV reports.

🧠 Architecture and Integrated Artificial Intelligence (AI)
The project is structured to support advanced data processing workflows and AI-driven predictive decision-making:

Real-Time Data Orchestration: Optimized asynchronous communication between the relational database (SQLite/SQLAlchemy) and Flask REST endpoints.

Predictive Analytics & Logistics Engines: Prepared to integrate Machine Learning models focused on geographic route optimization, fleet predictive maintenance, and intelligent driver allocation based on historical performance.

Dynamic Internationalization (i18n): Scalable modular structure for automated interface and report translations targeting the global market.

🛠️ Tech Stack
Backend: Python, Flask, Flask-SQLAlchemy, SQLite, RESTful API.

Frontend: React, Vite, JavaScript (ES6+), Custom CSS3, Lucide Icons.

Advanced Features: Real-time dynamic filters, fleet occupancy charts, CSV report exporting, and multi-language support (PT/EN).
